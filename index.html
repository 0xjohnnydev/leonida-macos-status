Steps to a playable scene

10 complete 1 in progress 2 upcoming
  1. Stage 1

    Verify the Xbox package against its manifest

    The manifest lists the expected SHA-256 fingerprint of each file. All 108 files in Xbox build 1.0.2.1 matched.

    Complete
  2. Stage 2

    Compile and link Xbox shader batches for Metal

    The Mac compiled a batch of 2,638 shader entries into Metal libraries. A separate set of 207 pixel shaders linked across 86 graphics pipeline configurations.

    Complete
  3. Stage 3

    Verify offscreen rendering with game shaders

    Two tests ran game shaders on the M5 Pro. One drew a solid color and the other drew a gradient. Each test checked all 4,096 pixels against its expected result.

    Complete
  4. Stage 4

    Translate x86-64 startup code to arm64

    The first startup build linked 88,740 blocks of Xbox CPU instructions into a Mach-O executable, the format macOS runs directly. The build that passed callback startup contained 546,787 arm64 blocks.

    Complete
  5. Stage 5

    Load the executable and initialize its libraries

    The Mac loader mapped the Xbox executable and seven bundled libraries. All seven initialized, and two callbacks for thread-local storage returned before the game reached its entry point.

    Complete
  6. Stage 6

    Initialize memory and the offline Xbox runtime

    The game opened the Metal device and made seven successful virtual-memory allocations. Its 1,115-entry C initialization table finished, and the offline Xbox runtime started.

    Complete
  7. Stage 7

    Connect the Xbox task queue and app-state callbacks

    The game created its Xbox task queue and registered both lifecycle handlers. A translated-code test ran a callback on a separate Mac thread. Local event tests delivered suspend, resume, and focus changes.

    Complete
  8. Stage 8

    Complete offline platform startup

    The game completed offline startup far enough to register, create, and show its own 3,840 × 2,160 window. It then requested ID3D12Device11, its graphics device interface.

    Complete
  9. Stage 9

    Bind Direct3D 12 buffers and textures to Metal

    The game bound shared buffers, both 4K display textures and its first uploaded texture to Metal. It linked six render pipelines and read local package data through 17 streaming queues.

    Complete
  10. Stage 10

    Submit the game’s GPU commands to Metal

    The Mac issued frame token 1. The game submitted its own command list for that frame, and Metal reported completion with two synchronization barriers.

    Complete
  11. Stage 11

    Present a game-rendered frame in a Mac window

    All five milestones in the Mac monitor are verified. The game asked to display frame 1 from a 3,840 × 2,160 texture. The Mac drew it into the game window at its 16:9 shape, and macOS reported the time it reached the display. The frame is black, which matches the clear color the game chose. The game then placed four more render targets and created the views it draws through.

    In progress

    Load geometry and textures from the local package. Move the character through the scene and verify that new assets load while input and successive frames continue.
